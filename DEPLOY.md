# Deployment and operations

Requires Node.js 22+; there are no runtime package dependencies. For local development, copy `.env.example` to `.env`, choose a strong `ADMIN_PASSWORD`, and run `node --env-file=.env server.mjs`. Alternatively set the environment variables in your shell and run `npm start`. Visit `http://127.0.0.1:4173/`, with `/#admin` for moderation. `GET /health` responds with `{"status":"ok"}` after the data store loads.

For production, the server binds to `0.0.0.0` by default and uses the `PORT` provided by the hosting platform. Set a unique `ADMIN_PASSWORD` (12+ characters), `PUBLIC_ORIGIN=https://your-public-host` (exact origin, no slash), and `DATA_DIR` to a **persistent writable directory** owned by the server process. Configure HTTPS at the reverse proxy, forward the original Host, and serve this app at that origin; do not expose the HTTP backend directly to the internet. The admin cookie is `HttpOnly`, `SameSite=Strict`, and uses `Secure` when `PUBLIC_ORIGIN` is HTTPS even with proxy TLS termination. Only one server process should write to a given `DATA_DIR`; the JSON file is not a multi-writer database. Back up `DATA_DIR/store.json` and test restoration.

All submissions start pending. Open the admin desk to approve/reject links and edit the manifesto. No political claims or demands are seeded by the backend. Admin sessions expire after 30 minutes and live only in server memory (a restart logs admins out). Rate limiting is per process and socket IP; use deployment-level rate limits and spam controls when deploying publicly. Browser previews load external sources only on a visitor click; the server does not fetch submitted URLs, upload files, or accept HTML/embed code. The URL must use public HTTPS. YouTube links must identify a video; X/Reddit links must identify a post. Unknown public HTTPS pages are classified as article links, and image filename extensions and selected image hosts are recognized as images. Moderators must review every source before approving it.

Run `npm test` and `npm run check` before deployment. If the process cannot create/read the data directory it fails startup; write errors return 500 without publishing the affected submission. Stop via SIGTERM/SIGINT to close the listening server gracefully.
